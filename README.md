# 📊 Vrinda Store Sales Data Analysis Dashboard

## Overview
This project focuses on analyzing Vrinda Store sales data using Microsoft Excel. The goal is to identify sales trends, customer behavior, top-performing states, order status distribution, and channel-wise performance through an interactive dashboard.

## Project Objectives
- Analyze monthly sales and order trends
- Identify top-performing states
- Understand customer demographics
- Compare sales by gender and age group
- Evaluate sales channel performance
- Track order status and fulfillment

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning
- Data Visualization
- Dashboard Design

## Key Insights
- Women customers contributed more sales than men.
- Adult age group generated the highest revenue.
- Amazon was the leading sales channel.
- Maharashtra, Karnataka, and Uttar Pradesh were the top-performing states.
- Most orders were successfully delivered.

## Dashboard Features
- Monthly Sales vs Orders Analysis
- Sales by Gender
- Sales by Age Group
- Order Status Distribution
- Top 5 States by Sales
- Sales Channel Performance
- Interactive Dashboard Filters

## Dataset
The dataset contains:
- Order Details
- Customer Information
- Gender & Age Group
- State Information
- Sales Amount
- Order Status
- Sales Channel
- Product Categories
